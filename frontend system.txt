## 1. Executive Summary

The [`frontend/`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend) application is a **modern full-stack SSR web application** built with **TanStack Start**, **React 19**, **Tailwind CSS v4**, and **Supabase**. It represents the digital customer-facing portal and lead engine for **Mapleleaf Moving Co**, a Toronto-based moving company operating since 2009.

The application is largely functional, featuring a custom quoting calculation engine, address autocomplete integration, and authenticated customer dashboard for booking requests. However, our audit revealed **critical disconnects** between the homepage quick-quote tool and the quoting engine, mock/unconnected contact form submissions, missing environment variables in local configuration, and styling/navigation inconsistencies.

## 4. Business Logic & Pricing Engine Analysis

The pricing algorithm in [`quote-engine.ts`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/lib/quote-engine.ts) is well-structured and handles realistic moving economics:

- **Crew Rates & Sizing**:
  - 2 movers: $139/hr (up to 520 cu ft)
  - 3 movers: $189/hr (521–950 cu ft)
  - 4 movers: $239/hr (>950 cu ft)
- **Minimum Hours**: 3-hour minimum floor enforced on all moves.
- **Fixed Costs**: Flat truck & equipment fee of $90.00 (`TRUCK_FEE_CENTS = 9000`).
- **Distance Surcharge**: First 30 km free; $1.60/km thereafter (`LONG_HAUL_PER_KM_CENTS = 160`).
- **Stairs Time Additions**:
  - 1 flight: +25 mins
  - 2 flights: +45 mins
  - 3+ flights: +75 mins
- **Dynamic Multipliers**:
  - **Peak Days**: +15% surcharge on weekends (Saturday/Sunday) and month-end dates (2 days before or 1 day after end of month).
  - **Arrival Windows**: Morning (8–10 AM) +5%, Midday (11 AM–1 PM) 1.0x, Afternoon (2–4 PM) -5%.
  - **Flexible Date Discount**: -5% subtotal discount if client checks "My dates are flexible".
- **Deposit Requirement**: 15% of estimated low price, rounded to the nearest $5.00 (minimum $100.00).

## 5. Database Schema & Data Flow

Database migrations are defined in [`supabase/migrations/`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/supabase/migrations):

```
┌──────────────┐       1:N       ┌──────────────┐       1:1       ┌──────────────┐
│ auth.users   ├────────────────►│    quotes    ├────────────────►│   bookings   │
└──────┬───────┘                 └──────────────┘                 └──────┬───────┘
       │ 1:1                                                             │ 1:N
       ▼                                                                 ▼
┌──────────────┐                                                  ┌──────────────┐
│   profiles   │                                                  │booking_events│
└──────────────┘                                                  └──────────────┘
```

- **`profiles`**: User metadata (full name, phone, email).
- **`quotes`**: Stores full quote parameters (`inventory` JSONB, route, home size, pricing in cents, contact details). Public `anon` users have permission to insert quotes with `user_id IS NULL`. Authenticated users can view and edit their own quotes.
- **`bookings`**: Stores confirmed moves created from accepted quotes with `deposit_status: 'pending'`, `agreement_name`, and timestamp.
- **`booking_events`**: Audit log of milestone events for a move.

## 6. Key Deficiencies, Bugs & Risks

### ⚠️ Critical Findings

1. **Homepage Hero Quick Quote Form is Disconnected from Database & Missing Contact Inputs**:
   - In [`index.tsx:L179-275`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/routes/index.tsx#L179-L275), the hero form provides fields for *From*, *To*, *Home Size*, and *Date*, but has **no input for Name, Email, or Phone**.
   - Submitting this form runs `setSubmitted(true)` client-side and renders: *"Thanks! We'll call you at the number on file within one business hour."*
   - No data is sent to Supabase or transmitted anywhere, and no phone number was ever collected.
   - **Impact**: Any lead attempting to book via the hero form is lost silently without notification.

2. **Contact Page Form is a Mock Submission**:
   - In [`contact.tsx:L26-30`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/routes/contact.tsx#L26-L30), the `submitMessage` handler simply calls `event.preventDefault()`, sets `sent = true`, and resets the form.
   - There is no database table for contact inquiries, no email dispatch via SMTP/Resend, and no API call.
   - **Impact**: Inquiries sent through the contact form are permanently lost upon page refresh.

3. **Missing Environment Variables for Google Maps Server Functions**:
   - [`maps.functions.ts:L6-17`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/lib/maps.functions.ts#L6-L17) expects `process.env["LOVABLE_API_KEY"]` and `process.env["GOOGLE_MAPS_API_KEY"]`.
   - In [`.env`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/.env), only `VITE_LOVABLE_CONNECTOR_GOOGLE_MAPS_BROWSER_KEY` is present.
   - **Impact**: When run locally or outside Lovable's hosted infrastructure, address autocomplete returns empty lists and distance calculation fails with a fallback error.

4. **Missing Binary Assets for Background Wallpaper**:
   - [`src/assets/`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/assets) contains `.asset.json` descriptors for `maple-pattern-background.jpg`, `maple-red-background.jpg`, etc., but the actual image files are missing.
   - As a result, [`site-shell.tsx:L33`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/components/site-shell.tsx#L33) and [`index.tsx:L82`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/routes/index.tsx#L82) only render a flat color gradient overlay without the intended maple wallpaper pattern.

5. **Inconsistent Header & Footer Implementation**:
   - [`index.tsx`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/routes/index.tsx) does not use [`PageShell`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/components/site-shell.tsx#L32), [`SiteHeader`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/components/site-shell.tsx#L6), or [`SiteFooter`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/components/site-shell.tsx#L23).
   - The homepage navigation has links to `#services` and `Pricing`, but **omits the link to `/portal` ("My move")**.
   - The homepage footer does not include the company logo image, unlike [`SiteFooter`](file:///e:/Fiverr/Gig/Gig%2013/Order/Project%200007/Maple-Leaf-Moving-Co/frontend/src/components/site-shell.tsx#L23).

6. **Deposit Payment Integration Incomplete**:
   - Online payment processing (Stripe) is not wired up; deposits are left in a `pending` status with manual outreach notes.
